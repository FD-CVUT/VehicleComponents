# The `dyad` command-line tool

`dyad` compiles Dyad component libraries to Julia/ModelingToolkit, sets up and checks the machine they are compiled on, and keeps the artifacts simulations produce in a queryable store. This skill was generated by `dyad` 3.5.0; if `dyad --version` reports something else, run `dyad install skills` to regenerate it.

Each command below links to a reference file with its full options and examples. Read that file before using a command's options, rather than guessing them; `dyad <command> --help` shows the same information.

## Workflows

- **Check the machine first.** `dyad doctor` reports what is wrong with the Julia setup and JuliaHub sign-in, and changes nothing. `dyad install` fixes what it can: `dyad install julia` for the toolchain, `dyad install skills` for agent skills. Every install command takes `--dry-run`; steps that download and run something need `--yes`.
- **Sign in before installing private packages.** `dyad auth login` authenticates with JuliaHub and stores the token where Julia's package manager and the `jh` tool look for it. `dyad auth status` shows whether the stored token is still valid.
- **New library.** `dyad create <Name>` writes a Julia package with a `dyad/` folder and compiles it once. Then edit the `.dyad` files and run `dyad compile` in the library, or `dyad compile --watch` while editing.
- **Lay out a diagram.** `dyad layout <Component> --dir <dir>` lays it out and writes it back. To improve a layout, work on a scratch file: `dyad layout extract <Component> --dir <dir> -o prob.json`, edit only its `settings`, `hints` and `constraints` (never `structure`), then `dyad layout solve -i prob.json -o sol.json --render sol.svg` and look at the SVG, repeating until it is right; `dyad layout apply <Component> --dir <dir> -i sol.json` writes it. `solve`'s stderr lists constraints it dropped or could not satisfy.
- **Exit status.** A command exits 1 only when it found an error; warnings alone exit 0. Diagnostics go to stderr, so commands that print a result (`parse`, `flatten`, `reference`) can be piped.
